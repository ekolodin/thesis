# Проблемы безопасности для больших языковых моделей в мультимодальном сценарии

 - `/chapters`: индивидуальные файлы `.md` или `.tex` для каждой главы
 - `/references`: библиографические файлы и Markdown-версии обработанных статей
 - `/data`: наборы данных или фрагменты кода, используемые в анализе.
